## 🏢 SAP Work

Most of my professional work lives in private client repositories, so here is what it covers:

- 🔷 **SAP BTP development:** SAP CAP, Fiori / UI5, SAP Integration Suite (CPI)
- 🔷 **E-compliance engineering:** the integrations behind AADE myDATA, e-Delivery and e-invoicing with SAP Document and Reporting Compliance (DRC)
- 🔷 **Business AI:** Joule, Joule Studio and agentic solutions on SAP BTP
